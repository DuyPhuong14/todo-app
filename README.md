# To-do App

Ứng dụng quản lý công việc – bài thực hành Tuần 4 (React Developer).

## Công nghệ
React, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Hook Form, Zod

## Tính năng
- Thêm, sửa, xóa, đánh dấu hoàn thành công việc
- Tìm kiếm và lọc theo trạng thái (Tất cả / Chưa xong / Đã xong)
- Phân trang (5 công việc mỗi trang)
- Form kiểm tra dữ liệu bằng React Hook Form + Zod
- Giao diện responsive (mobile và desktop)

## Cách chạy
```bash
npm install
npm run dev
```
Mở http://localhost:5173
